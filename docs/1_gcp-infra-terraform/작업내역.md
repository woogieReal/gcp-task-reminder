### 주요 결정 사항
- **google provider `~> 8.0`, random `~> 3.7`로 고정:** `secret_data_wo`는 6.23.0에서 추가됐지만 8.0.0에서 `secret_data_wo_version`이 문자열 타입으로 바뀌었다. 범위를 열어두면 컴퓨터마다 메이저 버전이 달라져 타입 오류가 날 수 있어 최신 메이저로 고정하고, 버전 변수를 문자열(`"1"`)로 정의했다.
- **비밀값을 tfstate에 남기지 않음:** 봇 토큰은 ephemeral 변수, 세션 키는 ephemeral `random_password`로 만들고 write-only 속성으로 넣었다. `*_version` 변수를 올릴 때만 새 값이 기록되는 트레이드오프가 있다.
- **결정적 URL + postcondition:** Cloud Run이 자기 URL을 환경 변수로 참조하면 순환 의존이 생기므로 프로젝트 번호로 URL을 계산했다. 계산이 틀리면 OIDC audience와 OAuth 원본이 어긋나므로 postcondition으로 apply 단계에서 차단한다.
- **이미지 변경은 Terraform이 무시:** 앱 배포는 GitHub Actions가 담당하므로 `ignore_changes`로 이미지·client 정보를 제외했다.
- **`cloudresourcemanager` API 추가:** 블루프린트 목록에 없었지만 `data.google_project`(프로젝트 번호 조회)가 의존하므로 다른 프로젝트에서의 재현성을 위해 명시했다.
- **봇 토큰 재발급 후 적용:** 초기 블루프린트에 노출됐던 토큰 대신 새로 발급한 토큰을 Secret Manager에 저장했다.
- **실행 주체 분리:** `apply`는 사용자가 실행하고, 에이전트는 더미 토큰으로 읽기 전용 `plan`까지만 수행했다. write-only 값은 plan에 나타나지 않으므로 더미 값으로도 검증 결과가 같다.

### 이슈 & 해결
- **블루프린트와 코드의 API 목록 불일치** (1차 검증 NEED_ACT): 블루프린트 Phase 1 `apis.tf` 명세에 `cloudresourcemanager`와 사유를 추가했다.
- **작업계획 변경 대상 파일 누락**: 1단계 확인 결과를 반영한 `docs/blueprint.md` 수정을 변경 대상 파일 표에 추가했다.
- **lock 파일이 linux_amd64 해시만 포함**: macOS 컴퓨터에서 `init` 시 lock 파일 diff가 생기는 문제를 막기 위해 `terraform providers lock`으로 linux_amd64, darwin_arm64, darwin_amd64 해시를 기록했다.
- **봇 토큰 입력 방법 혼동**: `read -rs`는 실행 후 입력을 기다리는 방식이며, 토큰에 `bot` 접두어를 붙이지 않아야 한다는 점을 안내했다. 저장된 값이 `숫자:문자열` 형식(46자)인지 값 노출 없이 확인했다.
- **다음 task로 이월**: 배포 SA의 서비스 단위 `run.developer` 충분성(task 6), `cloudtasks.tasks.fullView` 권한(task 3), GitHub Environment Variables 등록(task 6 전).
